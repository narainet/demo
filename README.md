개발·운영하기 위한 문서·도구 일체입니다.

## 2. 세 제품의 관계

셋은 **같은 코드베이스에서 갈라져 나온 형제**입니다. 공통 기반(전자정부 표준
공통컴포넌트 + 사용자·권한·메뉴·게시판)은 동일하고, 도메인 모듈만 다릅니다.

| 제품 | 규정관리 `/rlms/**` | 송무 `/law/**` | 테이블 | 용도 |
|---|:---:|:---:|---:|---|
| **RLMS** | ● | ● | 95 | 통합본. 두 업무를 한 시스템에서 |
| **RegNex** | ● | ✕ | 77 | 규정관리만 도입하는 고객 |
| **LexPortal** | ✕ | ● | 59 | 송무만 도입하는 고객 |

> 셋 다 각각 독립적으로 빌드·기동됩니다. 하나만 쓸 것이라면 나머지 둘은 **참고용
> 보관**으로 두면 됩니다. 전부 띄워서 비교하려면 포트를 나눠야 합니다
> (`docs/02_설치_가이드.md` §5).

## 5. 기술 스택 요약

| 구분 | 내용 |
|---|---|
| 프레임워크 | 전자정부 표준프레임워크 **4.3.0** (Spring 5.3.37) |
| JDK | **1.8** (Java 9+ 문법 사용 불가 — `var`, Record, Text Block 금지) |
| 빌드 | Maven (`mvn -o compile`) |
| WAS | Apache Tomcat **9.0** (정본) · **10.0 / 11.0** 도 배포 시 변환 1회로 동작 — `docs/08` §1 |
| 영속성 | MyBatis 3.5 (XML 매퍼) |
| DBMS | Oracle / MariaDB / PostgreSQL **3종 모두 지원** (`Globals.DbType` 로 선택) |
| 화면 | JSP + 태그파일 레이아웃 셸(`WEB-INF/tags`) + KRDS 디자인 시스템 |
| 보안 | Spring Security (URL 인가는 **DB 메뉴 테이블이 단일 원천**) |

## 6. 문의 시 함께 보내주시면 좋은 것

문제가 생겼을 때는 아래를 함께 알려주시면 원인 파악이 빠릅니다.

- Tomcat 콘솔 로그 (기동 실패 시 특히 `context-datasource` 관련 줄)
- `Globals.DbType` 값과 사용 중인 DBMS 버전
- 재현 URL 과 로그인한 계정의 권한(ROLE)
